# Record Evidence

This folder stores project evidence for the Upwork Expert Test demo.

- `logs.md`: implementation and verification log.
- `memory-report.md`: local storage and session-state report.
- `memory-leak-report.md`: memory leak review notes.
- `testcases.md`: functional testcase checklist.
- `coverage-report.md`: coverage evidence summary.
- `images/`: SVG evidence cards that can be opened as images.

Latest requested additions:

- Candidate must enter name and short description on the first screen.
- Candidate can press **Save profile** so admin can see the saved profile.
- Browser tab icon uses `public/assets/upwork-logo.svg`.
- Upwork-like assets are stored in `public/assets/`.
